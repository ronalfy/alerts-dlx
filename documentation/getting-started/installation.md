# Installation

## Install from the WordPress Admin

<!-- TODO: image - images/alerts-dlx-back-end-screenshot.jpg -->
<!-- Caption: Singular Alerts Block in the Block Editor -->

1. Log into your WordPress admin (your dashboard).
2. Go to **Plugins → Add New**.
3. Search for **Singular Alerts** (or **AlertsDLX**).
4. Click **Install Now**, then **Activate**.

After activation, Singular Alerts blocks are available in the block editor. Site-wide options are available under **Settings → AlertsDLX**. See [Finding the Admin Settings](finding-the-admin-settings.md).

## Requirements

* WordPress 6.9 or newer
* PHP 8.0 or newer
