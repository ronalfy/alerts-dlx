# Use Cases

Singular Alerts is more than a beautiful alert block in post content. Here are popular ways to use it on your site.

### Documentation and Knowledge Base Callouts

Use tips, notes, warnings, prerequisites, and step summaries in tutorials and knowledge base articles. Pair different alert types (info, success, warning) with variants like left-accent or solid for visual hierarchy.

### Editorial Workflow

Mark blocks as **Editorial Only** so author notes and review reminders stay in the block editor and never publish to the frontend. For example, add a note above a paragraph indicating it should not be edited for legal reasons. See [Editorial-Only Blocks](editorial-only-blocks.md).

### CTAs and Promos

Combine title, description, and button for downloads, newsletter signups, event promos, or "read more" nudges. Button link options support new-tab behavior and `rel` attributes for nofollow or sponsored links.

### Branded Message Boxes

Use custom colors and four design-system themes (Bootstrap, Material, Chakra, Shoelace) for a consistent branded look across your site.

### Flexible Content Panels (Advanced)

Enable **Flexible InnerBlocks (Advanced)** to add lists, images, and other blocks inside the styled alert shell. Inner block styling beyond basic paragraph text may depend on your theme. See [Flexible Inner Blocks](flexible-inner-blocks.md).

### Template and Global Messaging

Place notifications in Full Site Editing template parts, headers, or footers for site-wide or section-specific notices. Combine with [Dismissible Alerts](dismissible-alerts.md) so visitors can hide a notice and have it stay hidden.

### Shortcode Embeds

Output callouts in page builders, widgets, or form plugin areas (such as empty-cart or confirmation messages) anywhere shortcodes are supported. See [Shortcode Usage](../shortcodes/alertsdlx.md).

### Conditional Messaging

Pair Singular Alerts with plugins like [Block Visibility](https://blockvisibilitywp.com/) for logged-in-only notices, role-based messages, cart states, and scheduled promos.

### Compliance and Disclaimers

Create reusable affiliate, legal, medical, or financial disclaimer boxes with consistent styling across your site.
