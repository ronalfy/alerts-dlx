# AlertsDLX

Create styled alerts, tips, warnings, and callout boxes for the WordPress block editor, Full Site Editing templates, and anywhere shortcodes are supported. Four themes are included: Bootstrap, Chakra, Material, and Shoelace.

```bash
npm install
npm run start   # Watch / development build
npm run build   # Production assets
npx grunt       # Package alerts-dlx.zip
```
